# BookMoment プライバシーポリシー

施行日: 2026年8月10日

運営者: Moonworks

プライバシーに関する連絡先: icecrao2@icloud.com

このプライバシーポリシーは、BookMoment（以下「本アプリ」）が読書記録、メモ、写真メモ、書籍検索、通知、同期機能に関連して取り扱うデータを説明します。本アプリはアプリ内アカウントなしで利用でき、読書ライブラリをローカル優先で扱う設計です。

## 1. 取り扱うデータ

本アプリは、次のデータを端末またはユーザーの個人 iCloud ストレージに保存することがあります。

- 書籍情報: タイトル、著者、出版社、副題、ISBN またはバーコード由来の識別情報、カテゴリ、表紙画像 URL、ユーザーが選んだ色、評価
- 読書状態と再読記録: 読みたい、読書中、完読などの状態、回数、開始日、完了日、目標日、進捗
- メモと感想: ユーザーが入力したテキストメモ、引用、感想のタイトルと本文
- 写真メモ: 撮影または選択した画像、画像上に追加したテキスト、マーク、色、線、編集情報
- OCR 結果: 選択した画像から端末内処理で抽出されたテキスト
- 読書タイマーと統計: 読書セッションの日付、開始・終了時刻、継続時間、タイマーメモ、目標、集計統計
- 検索設定と最近の検索: 検索語、ISBN、バーコード、選択した検索方式、設定したプロキシ URL
- アプリ状態: 実行中の読書タイマー、読書冊数ウィジェット用スナップショット、通知設定
- 分析と通知のメタデータ: Firebase が有効なビルドでは、アプリ起動、書籍追加、メモ保存、タイマー開始・一時停止などのイベント名、限定的な数値・状態パラメータ、アプリインスタンス識別子、通知トークン、通知の受信・開封メタデータが処理されることがあります。
- 広告と同意のメタデータ: ユーザーがリワード広告の視聴を選ぶと、Google Mobile Ads と User Messaging Platform（UMP）が、IP アドレス、端末・アプリ情報、利用可能な場合の広告識別子、IP から推定されるおおよその位置、診断情報、同意の選択、広告表示・操作、報酬完了情報を処理することがあります。本アプリは、読書ライブラリ、メモ、感想、写真、書籍検索語を AdMob に送信しません。

自由入力のメモ、感想、写真注釈に氏名、連絡先、機微な内容などを入力した場合、その内容もアプリデータに含まれます。本アプリはそれらの情報の入力を必須としていません。

## 2. 利用目的

本アプリは、データを次の目的にのみ利用します。

- 個人の読書ライブラリ、再読履歴、メモ、感想、写真メモの保存と表示
- 読書タイマー、カレンダー、統計、ウィジェット、ライブアクティビティ、状態通知の提供
- タイトル、著者、ISBN、バーコードによる書籍検索
- ユーザーが選んだ画像から OCR 引用を抽出
- ユーザーが開始した共有画像、PDF、システム共有機能の提供
- アプリの安定性、機能利用状況、プッシュ通知動作を理解するための限定的な分析
- 一定時間書籍検索を利用可能にする任意のリワード広告の提供、報酬完了の確認、広告同意とプライバシー選択の管理

運営者は、読書記録やメモを広告のパーソナライズ、データブローカーへの販売、アプリ横断トラッキングに使用しません。Google は、ユーザーの同意、地域、端末設定、Google のポリシーに応じて、パーソナライズ広告または非パーソナライズ広告を配信することがあります。

## 3. 保存場所と同期

本アプリの主なデータ保存先は `BookReportLibrary` ファイルフォルダです。iOS または macOS で iCloud コンテナを利用できる場合、`Documents/BookReportLibrary` が iCloud Drive 同期対象フォルダとして使われることがあります。iCloud を利用できない場合は、ローカルの Documents フォルダに保存されます。

対応ビルドまたは設定では、一部の読書ライブラリデータと写真添付ファイルが、ユーザーの Apple iCloud アカウントに紐づく非公開 iCloud/CloudKit ストアを通じて同期されることがあります。この場合、Apple が iCloud サービス提供の一環としてデータを処理します。運営者は、読書ライブラリの主保存先として独自のユーザーアカウントサーバーを運用しません。

## 4. 外部サービスと第三者による処理

次のサービスが機能提供のためにデータを処理することがあります。

- Apple iCloud、iCloud Drive、CloudKit: 同じ iCloud アカウントでサインインした端末間のファイルまたはレコード同期
- Firebase Analytics: アプリイベントと限定的な利用メタデータ
- Google AdMob と Google UMP: 任意のリワード広告、広告配信・測定、不正防止、同意収集、プライバシー選択。詳しくは [Google プライバシーポリシー](https://policies.google.com/privacy) と [Google サービスを利用するアプリからの情報の使用](https://policies.google.com/technologies/partner-sites) をご覧ください。
- Firebase Cloud Messaging、Apple Push Notification service: リモート通知と通知トークン
- Google Books、Open Library、Apple Books/iTunes Search、Kakao Book Search、韓国国立中央図書館 API、またはユーザーが設定した書籍検索プロキシ: 入力された検索語、ISBN、バーコードによる書籍検索
- Apple または Google のアプリ内レビュー機能: ユーザーがレビューを選択した場合に各プラットフォームが処理

オンライン書籍検索を行うと、検索語、ISBN、バーコードに加え、IP アドレスやリクエストヘッダーなど通常の接続メタデータが検索提供者に送信されることがあります。本アプリは、メモ、感想、写真原本を検索提供者へ送信する設計ではありません。

## 5. 権限

- カメラ: 書籍バーコードの読み取りと写真メモの撮影に使用します。
- 写真ライブラリ: ユーザーが選んだページ画像やメモ画像の取り込みに使用します。
- 通知: 読書タイマーの目標通知、アクティブ読書状態、アプリ更新、リマインダーに使用します。
- iCloud: Apple アカウントを通じてアプリデータのファイルまたはレコードを同期するために使われることがあります。

権限は OS 設定でいつでも変更できます。権限を無効にすると、関連機能が制限される場合があります。

## 6. 共有とエクスポート

共有画像、PDF、システム共有シートを利用すると、選択したコンテンツがユーザーの選んだアプリまたはサービスに渡されます。渡された後は、受け取り先のアプリまたはサービスのプライバシー方針が適用されます。

## 7. 保管と削除

読書ライブラリデータは、ユーザーが削除するか、アプリデータ、ローカルファイル、iCloud Drive の `BookReportLibrary` フォルダを削除するまで保持されます。最近の検索はアプリ内で個別に削除または一括削除できます。アプリを削除すると端末上のローカルアプリデータは OS の規則に従って削除されますが、iCloud Drive または iCloud バックアップ上のコピーは、iCloud 設定またはファイルアプリで別途管理が必要な場合があります。

Firebase Analytics、Messaging、AdMob、UMP のデータは Google/Firebase の保持ポリシーに従って処理されます。ストアレビュー、iCloud、プッシュ通知基盤で処理されるデータは、各プラットフォームのポリシーに従います。

## 8. 安全管理

本アプリは、可能な限り読書ライブラリの原本を端末ストレージまたは個人 iCloud ストレージに保存します。OCR は対応プラットフォームで端末内処理として実行されます。オンライン検索、Firebase、iCloud など通信が必要な機能では、各プラットフォームまたは提供者の HTTPS と認証システムを利用します。

## 9. 子どものプライバシー

本アプリは子どもを対象としておらず、子ども向けのアカウント作成やプロフィール作成を提供しません。任意のリワード広告は、地域の同意要件とプラットフォーム設定に応じて利用できる場合があります。保護者が子どもの利用を許可する場合は、広告の選択を監督し、入力される読書記録やメモを管理してください。

## 10. ユーザーの選択と権利

ユーザーは、アプリ内の編集・削除機能、端末のアプリデータ管理、ファイルアプリ、iCloud 設定を通じてデータを確認、修正、削除できます。プライバシーに関する質問や、アクセス、訂正、削除、処理制限の依頼は、icecrao2@icloud.com へ送信できます。

最初の3回の書籍検索は広告なしで利用でき、手動入力は常に広告視聴なしで利用できます。既存の非消耗型購入で広告を削除できます。必要な地域では、アプリ内に広告プライバシー設定への入口を表示し、端末設定でも適用可能な広告・プライバシー設定を変更できます。

## 11. 変更

アプリ機能、外部サービス、法的要件が変更された場合、この文書は更新されることがあります。重要な変更は、アプリまたは配信チャネルを通じて通知する場合があります。
