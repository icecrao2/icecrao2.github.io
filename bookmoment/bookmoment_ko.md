# BookMoment 개인정보 처리방침

시행일: 2026년 8월 10일

운영자: Moonworks

개인정보 문의: icecrao2@icloud.com

이 개인정보 처리방침은 BookMoment(이하 "앱")가 사용자의 독서 기록, 메모, 사진 메모, 도서 검색, 알림, 동기화 기능과 관련하여 어떤 데이터를 처리하는지 설명합니다. 앱은 계정 가입 없이 로컬 중심으로 동작하도록 설계되어 있으며, 사용자가 직접 입력하거나 선택한 독서 데이터가 핵심 데이터입니다.

## 1. 처리하는 데이터

앱은 기능 제공을 위해 다음 데이터를 기기 또는 사용자의 iCloud 저장 공간에 저장할 수 있습니다.

- 도서 정보: 제목, 저자, 출판사, 부제, ISBN 또는 바코드에서 가져온 식별 정보, 카테고리, 표지 이미지 URL, 사용자가 지정한 색상과 평점
- 독서 상태와 회독 기록: 읽고 싶은 책, 읽는 중, 완독 여부, 회독 번호, 시작일, 완료일, 목표일, 진행률
- 메모와 독후감: 사용자가 작성한 텍스트 메모, 인용문, 독후감 제목과 본문
- 사진 메모: 사용자가 촬영하거나 선택한 이미지, 이미지 위에 추가한 텍스트, 표시, 색상, 획 정보
- OCR 결과: 선택한 이미지에서 기기 내 OCR로 추출된 텍스트
- 독서 타이머와 통계: 독서 세션 날짜, 시작/종료 시각, 기간, 타이머 메모, 월간/연간 목표와 통계
- 검색 설정과 최근 검색어: 사용자가 입력한 도서 검색어, ISBN, 바코드, 선택한 검색 방식 또는 프록시 URL
- 앱 상태: 활성 독서 타이머, 위젯 표시용 독서 횟수 스냅샷, 알림 설정
- 분석 및 알림 메타데이터: Firebase가 활성화된 빌드에서는 앱 열기, 책 추가, 메모 저장, 타이머 시작/중지 같은 이벤트명과 제한된 숫자/상태 파라미터, 앱 인스턴스 식별자, 알림 토큰 및 알림 수신/열람 메타데이터가 처리될 수 있습니다.
- 광고 및 동의 메타데이터: 사용자가 보상형 광고 시청을 선택하면 Google Mobile Ads와 사용자 메시지 플랫폼(UMP)이 IP 주소, 기기·앱 정보, 사용 가능한 경우 광고 식별자, IP 기반 대략적 위치, 진단 정보, 동의 선택, 광고 노출·상호작용 및 보상 완료 여부를 처리할 수 있습니다. 앱은 사용자의 서재, 메모, 독후감, 사진 또는 도서 검색어를 AdMob에 보내지 않습니다.

사용자가 자유 입력란에 이름, 연락처, 민감한 내용 등을 직접 입력하면 그 내용도 앱 데이터에 포함될 수 있습니다. 앱은 이러한 정보를 입력하도록 요구하지 않습니다.

## 2. 처리 목적

앱은 데이터를 다음 목적에만 사용합니다.

- 개인 독서 서재, 회독 기록, 메모, 독후감, 사진 메모를 저장하고 다시 표시
- 독서 타이머, 캘린더, 통계, 위젯, 라이브 활동 또는 상태 알림 제공
- 도서 제목, 저자, ISBN, 바코드로 온라인 도서 검색 수행
- 사용자가 선택한 사진에서 OCR 인용문 추출
- 사용자가 직접 실행한 공유 이미지, PDF, 시스템 공유 기능 제공
- 앱 안정성, 기능 사용 현황, 푸시 알림 동작을 이해하기 위한 제한적 분석
- 일정 시간 도서 검색을 열어 주는 선택형 보상 광고 제공, 보상 완료 확인, 광고 동의 및 개인정보 선택 관리

운영자는 광고 개인화, 데이터 브로커 판매 또는 크로스 앱 추적 목적으로 독서 기록이나 메모를 사용하지 않습니다. Google은 사용자의 동의, 지역, 기기 설정 및 Google 정책에 따라 개인 맞춤 또는 비개인 맞춤 광고를 제공할 수 있습니다.

## 3. 저장 위치와 동기화

앱의 기본 저장소는 기기 안의 `BookReportLibrary` 파일 폴더입니다. iOS 또는 macOS에서 iCloud 컨테이너를 사용할 수 있으면 `Documents/BookReportLibrary`가 iCloud Drive 동기화 대상 폴더로 사용될 수 있고, 사용할 수 없으면 로컬 Documents 폴더로 저장됩니다.

지원되는 빌드 또는 설정에서는 일부 독서 라이브러리 데이터와 사진 첨부 파일이 사용자의 Apple iCloud 계정에 연결된 비공개 iCloud/CloudKit 저장소를 통해 동기화될 수 있습니다. 이 경우 데이터 처리는 Apple의 iCloud 서비스 제공 범위 안에서 이루어집니다. 운영자는 별도의 사용자 계정 서버를 통해 독서 라이브러리 원본을 기본 저장소로 운영하지 않습니다.

## 4. 외부 서비스와 제3자 처리

다음 서비스가 기능 제공을 위해 데이터를 처리할 수 있습니다.

- Apple iCloud, iCloud Drive, CloudKit: 사용자의 iCloud 계정 기기 간 파일 또는 레코드 동기화
- Firebase Analytics: 앱 이벤트와 제한된 사용 메타데이터 분석
- Google AdMob 및 Google UMP: 선택형 보상 광고 제공·측정, 부정 행위 방지, 동의 수집 및 개인정보 선택 제공. 자세한 내용은 [Google 개인정보처리방침](https://policies.google.com/privacy)과 [Google 서비스를 사용하는 앱에서의 정보 이용 방식](https://policies.google.com/technologies/partner-sites)을 확인해 주세요.
- Firebase Cloud Messaging, Apple Push Notification service: 원격 알림과 알림 토큰 처리
- Google Books, Open Library, Apple Books/iTunes Search, Kakao Book Search, 국립중앙도서관 API 또는 사용자가 설정한 도서 검색 프록시: 사용자가 입력한 검색어, ISBN, 바코드로 도서 검색
- Apple/Google 인앱 리뷰 기능: 사용자가 스토어 리뷰 흐름으로 이동할 때 각 플랫폼이 처리

온라인 도서 검색을 실행하면 검색어, ISBN, 바코드와 함께 네트워크 요청에 필요한 IP 주소, 기기/브라우저 헤더 등 연결 메타데이터가 해당 제공자에게 전달될 수 있습니다. 앱은 도서 검색 제공자에게 사용자의 메모, 독후감, 사진 원본을 보내도록 설계되어 있지 않습니다.

## 5. 권한 사용

- 카메라: 도서 바코드 스캔, 사진 메모 촬영에 사용합니다.
- 사진 보관함: 사용자가 선택한 페이지 이미지 또는 메모 이미지를 가져오는 데 사용합니다.
- 알림: 독서 타이머 목표 알림, 활성 독서 상태, 앱 업데이트 또는 리마인더 알림에 사용합니다.
- iCloud: 사용자의 Apple 계정에서 앱 데이터 파일 또는 레코드를 동기화하는 데 사용될 수 있습니다.

권한은 운영체제 설정에서 언제든지 변경할 수 있습니다. 권한을 끄면 관련 기능이 제한될 수 있습니다.

## 6. 공유와 내보내기

사용자가 공유 이미지, PDF, 시스템 공유 시트를 실행하면 선택한 콘텐츠가 사용자가 고른 앱 또는 서비스로 전달됩니다. 전달 후 해당 앱 또는 서비스의 개인정보 처리방침이 적용됩니다.

## 7. 보관과 삭제

독서 라이브러리 데이터는 사용자가 삭제하거나 앱 데이터, 로컬 파일, iCloud Drive의 `BookReportLibrary` 폴더를 삭제할 때까지 보관됩니다. 최근 검색어는 앱에서 개별 삭제 또는 전체 삭제할 수 있습니다. 앱을 삭제하면 기기의 로컬 앱 데이터는 운영체제 정책에 따라 삭제되지만, iCloud Drive 또는 iCloud 백업에 남아 있는 데이터는 사용자가 iCloud 설정 또는 파일 앱에서 별도로 관리해야 할 수 있습니다.

Firebase Analytics, Messaging, AdMob 및 UMP 데이터는 Google/Firebase의 보관 정책에 따라 처리됩니다. 스토어 리뷰, iCloud, 푸시 알림 인프라에서 처리되는 데이터는 각 플랫폼의 정책에 따릅니다.

## 8. 안전성 확보 조치

앱은 가능한 한 독서 라이브러리 원본을 사용자의 기기 또는 개인 iCloud 저장 공간에 보관합니다. 사진 OCR은 지원되는 플랫폼에서 기기 내 처리로 수행됩니다. 온라인 전송이 필요한 검색, Firebase, iCloud 기능은 각 플랫폼 또는 제공자의 HTTPS 및 인증 체계를 사용합니다.

## 9. 아동의 개인정보

앱은 아동을 대상으로 하지 않으며 아동 대상 계정 가입이나 프로필 생성 기능을 제공하지 않습니다. 선택형 보상 광고는 지역별 동의와 플랫폼 설정에 따라 제공될 수 있습니다. 보호자가 아동의 앱 사용을 허용하는 경우 광고 선택을 감독하고 기기에 입력되는 독서 기록과 메모 내용을 관리해야 합니다.

## 10. 이용자의 선택과 권리

사용자는 앱 안의 편집/삭제 기능, 기기의 앱 데이터 관리, 파일 앱 또는 iCloud 설정을 통해 데이터를 확인, 수정, 삭제할 수 있습니다. 개인정보 관련 문의, 접근·정정·삭제 요청, 처리 제한 요청은 icecrao2@icloud.com으로 보낼 수 있습니다.

최초 3회의 도서 검색은 광고 없이 사용할 수 있고, 직접 입력은 광고 시청 없이 항상 이용할 수 있습니다. 기존 비소모성 구매를 통해 보상형 광고를 제거할 수 있습니다. 필요한 지역에서는 앱 안에 광고 개인정보 설정 진입점을 제공하며, 기기 설정에서도 적용 가능한 광고 및 개인정보 설정을 변경할 수 있습니다.

## 11. 처리방침 변경

앱 기능, 외부 서비스, 법적 요구사항이 변경되면 이 문서가 업데이트될 수 있습니다. 중요한 변경사항이 있는 경우 앱 또는 배포 채널을 통해 고지할 수 있습니다.
