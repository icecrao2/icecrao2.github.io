# 개인정보처리방침

- 앱명: 루틴체크리스트 - 투두 & 오늘 습관
- 시행일: 2026-07-31
- 로컬 문안 갱신일: 2026-11-21

본 방침은 앱이 처리하는 정보, 이용 목적, 외부 서비스와 이용자의 선택 방법을 설명합니다.

## 1. 사용자가 입력한 데이터

사용자가 입력한 루틴과 수행 기록, 설정은 기기 내 앱 저장 영역에 저장됩니다.

사용자가 선택하고 기기에서 허용한 시스템 기능과 공유 대상을 통해 루틴 데이터나 이미지를 내보낼 수 있습니다. 이미지 저장과 공유는 운영체제 기능으로 처리됩니다.

## 2. 외부로 전송될 수 있는 정보

- iOS의 AI 루틴 설계에서 전송에 동의하면 루틴을 제안하기 위해 목표, 대화 내용과 요약, 앱 언어, 진행 중인 루틴의 이름과 반복 설정, 대화에서 사용하는 루틴 식별자를 Firebase Functions를 거쳐 OpenAI로 보냅니다. 설계 초안과 적용한 루틴은 기기에 저장합니다. Firebase 서버는 Apple의 서명된 구매 정보를 검증하고 설계권의 중복 사용을 막기 위해 거래와 목표의 해시, 이용 상태, 요청 횟수를 보관합니다. 전송에 동의하지 않아도 직접 루틴을 만들 수 있습니다.
- Firebase Analytics: 앱 실행, 기능 이용, 집계 수치, 결과 범주를 분석합니다. 사용자 입력 문장과 개별 루틴 ID는 자체 분석 이벤트에 포함하지 않습니다.
- Firebase Cloud Messaging: 운영 메시지 전달을 위해 앱 인스턴스 토큰과 전달 관련 정보가 처리될 수 있습니다. 토큰은 FCM SDK가 처리하며 앱 내 확인 정보는 기기에 보관합니다.
- Google Mobile Ads: 무료 버전의 광고 표시, 부정 사용 방지, 광고 성과 측정을 위해 광고 ID, IP 주소, 기기·앱 정보, 광고 상호작용, 진단 정보 등이 처리될 수 있습니다.
- Apple App Store / Google Play: 1회 구매와 구매 복원을 위해 스토어 계정, 거래, 구매 상태 정보가 각 스토어 사업자에 의해 처리됩니다. 앱은 결제 카드 정보를 직접 수집하지 않습니다.

실제 처리 정보는 기기, 운영체제, 지역, 개인정보 설정과 각 SDK 사양에 따라 달라질 수 있습니다.

## 3. 이용 목적

- 루틴 생성, 실행, 기록, 통계, 개선 제안 제공
- 알림, 위젯, 이미지 저장과 공유 제공
- 앱 이용 현황 집계와 품질 개선
- 광고 표시, 광고 성과 측정, 부정 사용 방지
- 1회 구매 처리와 구매 상태 복원
- 운영상 필요한 메시지 전달

## 4. 보관 기간

기기 내 데이터는 앱 저장 영역에 보관됩니다. 루틴 삭제는 이전 수행 이력을 보존하는 소프트 삭제이며, 앱을 제거하면 해당 기기의 앱 데이터도 제거됩니다. 운영체제 백업을 사용하면 백업 데이터는 운영체제 제공자의 설정과 보관 기간에 따라 남을 수 있습니다.

외부 서비스로 전송된 정보의 보관 기간은 각 서비스 제공자의 설정, 계약, 법령과 개인정보처리방침을 따릅니다.

## 5. 이용자의 선택

- 알림, 사진과 기타 시스템 기능의 권한은 운영체제 설정에서 변경할 수 있습니다.
- iOS 추적 권한은 표시될 때 거부하거나 나중에 운영체제 설정에서 변경할 수 있습니다.
- Android에서는 광고 ID 삭제·재설정과 광고 개인정보 설정을 사용할 수 있습니다.
- 앱을 삭제하면 기기 내 앱 데이터도 삭제되지만 운영체제 백업에는 일정 기간 남을 수 있습니다.

## 6. 제3자 서비스

- Google Firebase Analytics / Firebase Cloud Messaging
- Google Firebase Functions 및 OpenAI (iOS AI 루틴 설계)
- Google Mobile Ads
- Apple App Store / Google Play 인앱 구매
- 운영체제가 제공하는 알림, 사진, 공유, 백업과 권한 기반 시스템 기능

각 서비스는 자체 개인정보처리방침에 따라 정보를 처리합니다.

## 7. 아동의 개인정보

앱은 아동에게 이름, 이메일 주소 등 연락처 정보를 의도적으로 요구하지 않습니다. 보호자가 아동의 정보 처리에 관한 우려를 알게 된 경우 아래 연락처로 문의할 수 있습니다.

## 8. 보안

기기 내 데이터는 운영체제의 앱 저장 영역에 저장하며 외부 서비스와의 통신은 각 SDK와 운영체제가 제공하는 보호된 통신 수단을 사용합니다. 다만 전자적 저장이나 통신의 절대적인 안전을 보장할 수는 없습니다.

## 9. 방침 변경

기능, 외부 서비스 또는 법령 변경에 따라 본 방침을 갱신할 수 있습니다. 중요한 변경은 앱 또는 스토어 정보를 통해 안내합니다.
